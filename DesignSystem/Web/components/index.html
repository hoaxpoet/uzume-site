Components / Actions

Button

Triggers an action with explicit hierarchy and accessible loading or disabled behavior.

CSS · L3–36Behavior · L3–42
Canonical specimen

A signed beta has not been attached.

API and classes

.uz-button
Required base class on a native button.
.uz-button--primary
Primary action; one per decision region.
.uz-button--secondary
Supporting action.
.uz-button--quiet
Low-emphasis action.
.uz-button__spinner
Inserted by setUzumeBusy(button, true, label).

Token dependencies

--target-min-web--color-accent--color-accent-hover--color-accent-pressed--color-control-disabled-*--focus-ring--duration-immediate

Inspect foundation tokens

Accessibility requirements

  • Use a native button for actions; use Link for navigation.
  • Keep the visible label stable while loading; the helper supplies aria-busy and a progress label.
  • Associate a disabled reason with aria-describedby.
  • The 44 px minimum target comes from --target-min-web.

Copyable markup

<button type="button" class="uz-button uz-button--primary">
  Download beta
</button>

Components / Actions

Icon Button

A compact action for familiar media controls whose accessible name remains explicit.

CSS · L37–52
Canonical specimen

Playback controls are unavailable until media loads.

API and classes

.uz-icon-button
Required class; fixed 44 × 44 px target.
aria-label
Required accessible action name, updated when the action changes.
disabled
Native unavailable state.

Token dependencies

--target-min-web--color-line--color-surface-raised--color-surface-selected--color-text-disabled--focus-ring

Accessibility requirements

  • Every icon button needs an explicit accessible name.
  • Decorative SVGs use aria-hidden="true".
  • Update the name when Play becomes Pause.
  • Associate disabled context with aria-describedby when the reason is not obvious.

Copyable markup

<button type="button" class="uz-icon-button" aria-label="Play preview">
  <svg viewBox="0 0 24 24" aria-hidden="true">…</svg>
</button>

Components / Actions

Link

Navigates to another page, location, or resource without borrowing button styling.

CSS · L54–58
Canonical specimen
See performance media guidance

API and classes

.uz-link
Required base class on an anchor with a valid destination.
.uz-link--quiet
Secondary navigation or reference treatment.
.uz-link--unavailable
Plain-text unavailable treatment; never place it on an anchor.

Token dependencies

--color-text-primary--color-text-secondary--color-accent--color-accent-hover--color-text-disabled--focus-ring

Accessibility requirements

  • Link text describes its destination out of context.
  • Do not use href="#" as a placeholder.
  • Unavailable destinations are plain text, not focusable anchors.
  • External destinations must not rely on color alone for identification.

Copyable markup

<a class="uz-link" href="/gallery/">
  Explore certified presets
</a>

Components / Feedback

Banner

Reports availability, permission, installation, or beta guidance with conventional status cues.

CSS · L69–91
Canonical specimen

API and classes

.uz-banner
Root feedback region.
data-tone
info, success, warning, or danger.
__icon / __content
Required structural parts.
__title / __body / __actions
Message content; actions are optional.

Token dependencies

--color-status-info-*--color-status-success-*--color-status-warning-*--color-status-danger-*--color-text-primary--color-text-secondary

Accessibility requirements

  • Use icon, text, and conventional color together; color is never the only cue.
  • Add role="status" only when the banner is inserted or updated dynamically.
  • Use role="alert" only for time-sensitive errors requiring immediate attention.
  • Provide the consequence and a recovery action when one exists.

Copyable markup

<section class="uz-banner" data-tone="warning">
  <div class="uz-banner__icon" aria-hidden="true">…</div>
  <div class="uz-banner__content">
    <strong class="uz-banner__title">Beta unavailable</strong>
    <p class="uz-banner__body">A signed build has not been published.</p>
  </div>
</section>

API and classes

.uz-definition-list
Required class on a semantic dl.
dl > div
Groups each term and description pair.
dt / dd
Native term and description elements.

Token dependencies

--space-1--space-4--color-line--color-text-secondary

Accessibility requirements

  • Use a semantic dl; do not imitate the layout with generic divs.
  • Keep each term adjacent to its description in source order.
  • The layout stacks below 30rem without changing reading order.

<dl class="uz-definition-list">
  <div><dt>System</dt><dd>macOS 14 or later</dd></div>
</dl>

Media Frame

Presents image, video, or an explicit fallback with caption and attribution.

CSS · L98–106
Canonical specimen

API and classes

.uz-media-frame
Root figure.
__content
16:9 image or video viewport.
__fallback
Explicit missing-media state.
__caption / __meta
Title and attribution or provenance.

Token dependencies

--radius-lg--color-surface--color-canvas--color-text-secondary--measure-copy

Accessibility requirements

  • Image alt text describes the evidence, not its appearance alone.
  • Videos require captions when speech conveys meaning.
  • Controls compose from Icon Button and remain keyboard operable.
  • Fallback copy preserves title and attribution instead of fabricating footage.

Copyable markup

<figure class="uz-media-frame">
  <div class="uz-media-frame__content">
    <img src="/media/performance.jpg" alt="Uzume visuals responding to music">
  </div>
  <figcaption class="uz-media-frame__caption">…</figcaption>
</figure>

Components / Content

Preset Card

Identifies one preset through media, name, contributor, certification, and honest fallback states.

CSS · L149–159Responsive · L175–177
Canonical specimen

API and classes

.uz-preset-card
Root figure.
__media
16:9 preview or fallback.
__caption / __identity
Metadata grouping.
__title / __author / __status
Required name, contributor, and certification text.

Token dependencies

--radius-lg--color-surface--color-canvas--color-text-secondary--space-2--space-5

Accessibility requirements

  • Keep preset title and contributor available when media fails.
  • State certification in text; never encode it only with a badge color.
  • Preview controls compose from Icon Button.
  • Do not imply a performance capture exists when only identity artwork is available.

Copyable markup

<figure class="uz-preset-card">
  <div class="uz-preset-card__media">…</div>
  <figcaption class="uz-preset-card__caption">
    <span class="uz-preset-card__identity">…</span>
    <span class="uz-preset-card__status">Certified · 0 flashes/s</span>
  </figcaption>
</figure>
