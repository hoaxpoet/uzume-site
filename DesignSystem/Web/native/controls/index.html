Current app census

The Uzume system is derived from Phosphene’s working SwiftUI composition. The audit covered 49 view files and 57 named views or modifiers, including construction sites and state ownership.

Preserve

  • Session-state routing and source capability boundaries
  • Connector task lifetime and environment-injected stores
  • Preparation publishers, recovery, and progressive readiness
  • First-audio detection and local-only transport

Change deliberately

  • Hard-coded presentation and former palette
  • Duplicated source tiles and recovery layouts
  • Plan-preview behavior that reveals future choreography

Platform controls

Uzume does not redraw standard macOS controls. These SwiftUI components are part of the design-system inventory because their roles, allowed styles, sizes, and usage still require one shared contract.
