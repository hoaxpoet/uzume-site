Two displays, two responsibilities

The external display belongs to the Viewer. The Mac belongs to the Curator. Mirrored full-screen output remains the fallback when a separated controller is unavailable.

Build it consistently

A design system is a maintained agreement. New work extends it only when a reusable need is proven and the change can be tested.

Definition of done

  • Real content at compact and wide widths
  • Keyboard and visible focus

  • Reduced motion and increased contrast
  • Native convention review for app work

Contribution rule

Add a token only for a reusable decision. Add a component after repeated intent—or sooner when centralizing behavior materially improves accessibility. Document anatomy, variants, states, and one real example.
